# Notas del Entorno de Desarrollo - Alsina

Este archivo contiene las credenciales y URLs provisionales para acceder a la aplicación en el entorno de desarrollo local.

---

### Acceso a la Aplicación

Para levantar el entorno, se necesitan dos comandos en dos terminales separadas:
1.  `php artisan serve`
2.  `npm run dev`

---

### Credenciales de Inicio de Sesión

*   **URL de Acceso:** http://127.0.0.1:8000 (o la que indique el comando `php artisan serve`)
*   **Usuario:** `admin@admin.com`
*   **Contraseña:** `password`
